# AnchorIQ — Deployment Readiness Inventory (Phase 0)

This inventory audits all local disk dependencies, endpoint access requirements, and environment variables across the AnchorIQ codebase to prepare for deployment on ephemeral cloud hosts (Render / Hugging Face Spaces for FastAPI, Streamlit Community Cloud for the UI).

---

## 1. Local Disk Read/Write Audit

| Location / Path | Purpose & What Depends on It | Current Disk Operation | Deployment Target (Ephemeral Cloud) |
| :--- | :--- | :--- | :--- |
| `charts/` | EDA visualization PNG files generated by `auto_eda` and SHAP. | `os.makedirs`, `plt.savefig`, read for Cloudinary upload, static mount `/charts`. | **Eliminate disk storage.** Render matplotlib figures into in-memory `io.BytesIO` buffers and upload bytes directly to Cloudinary. Remove static `/charts` mount and delete `charts/` folder. |
| `models/` | Serialized model pipelines (`.pkl`) and schemas (`.json`) saved by `auto_model`. | `joblib.dump`, `json.dump`, local fallback `joblib.load` for predictions. | **Eliminate disk storage.** Return model bundle in memory from `auto_model`, serialize to bytes, and upload to Cloudinary as private raw asset. Load directly into memory via `download_private_file`. Store schema in `model_card`. Remove `models/` folder. |
| `uploads/` | Uploaded raw / cleaned datasets fallback used by A/B testing and agent chat. | `cleaned_df.to_csv` fallback in `app/main.py`, read by `services/agent.py` and `services/ab_testing.py`. | **Eliminate disk storage.** Store cleaned dataset as private raw asset on Cloudinary (`dataset_asset`). Download directly into memory (`pd.read_csv(io.BytesIO(...))`) for A/B testing and agent chat. Remove `uploads/` folder. |
| `reports/` | Generated executive PDF reports and enriched CSVs. | `os.makedirs`, ReportLab file build (`doc.build(output_path)`), `services/pipeline.py` CSVs. | **Eliminate disk storage.** Build PDF on demand directly into an in-memory `io.BytesIO` buffer via `GET /runs/{id}/report` and stream response. Do not store PDFs on disk or Cloudinary. Remove `reports/` folder. |
| `tempfile` | Temporary files in `app/main.py` and `services/loader.py`. | `tempfile.NamedTemporaryFile` used briefly during dataset upload. | Keep usage minimal and strict: use system temp directory only when an in-memory stream is impossible, wrapped in `try ... finally` with explicit deletion. |
| `anchoriq_local.db` (SQLite) | Emergency fallback database when Supabase is unreachable. | File-based SQLite database via SQLAlchemy in `database/db.py`. | **Eliminate SQLite fallback in production.** Require valid `SUPABASE_DB_URL`. Only use in-memory SQLite (`sqlite:///:memory:`) when running under automated tests (`pytest`). Delete local SQLite file and `.gitignore` it. |
| StaticFiles mount (`/charts`) | Serves local `charts/` directory over HTTP at `app.mount("/charts", ...)`. | Starlette static file directory handler. Requires folder to exist on startup. | **Remove completely.** All charts are served from authenticated/public Cloudinary CDN URLs. |
| `.mplconfig` | Matplotlib font and caching configuration directory. | Created at root; configured via `os.environ["MPLCONFIGDIR"]`. | Set `MPLCONFIGDIR` to the system temporary directory (`tempfile.gettempdir()`) so nothing is written to the project folder. Remove `.mplconfig` from repo and `.gitignore` it. |

## 2. API Endpoints & Authentication Access Requirements

| Endpoint | HTTP Method | Login Required After Redesign? | User Isolation & Ownership Behavior |
| :--- | :--- | :--- | :--- |
| `/health` | `GET` | **No** (Public) | System health and service configuration check. Exposes connectivity booleans without leaking secrets or URLs. |
| `/analyze` | `POST` | **Yes** (`get_current_user`) | Associates the created run record with the authenticated `user_id`. Sets `runs.user_id`. |
| `/runs` | `GET` | **Yes** (`get_current_user`) | Filters and returns only runs belonging to the authenticated `user_id`. |
| `/runs/{run_id}` | `GET` | **Yes** (`get_current_user`) | Verifies ownership. Returns 404 if the run does not exist or belongs to another user. |
| `/runs/{run_id}` | `DELETE` | **Yes** (`get_current_user`) | Verifies ownership. Deletes run record and associated Cloudinary assets. Returns 404 if not owned. |
| `/runs/{run_id}/report` | `GET` | **Yes** (`get_current_user`) | Verifies ownership. Generates executive PDF in memory from run details & Cloudinary charts and streams to user. Returns 404 if not owned. |
| `/predict/schema/{run_id}` | `GET` | **Yes** (`get_current_user`) | Verifies ownership. Returns input feature schema for UI dynamic form. Returns 404 if not owned. |
| `/predict/{run_id}` | `POST` | **Yes** (`get_current_user`) | Verifies ownership. Loads model bundle into memory from Cloudinary and performs inference. Returns 404 if not owned. |
| `/ab_test` | `POST` | **Yes** (`get_current_user`) | If `run_id` is passed, verifies run ownership and fetches dataset from Cloudinary into memory. Returns 404 if not owned. |
| `/chat/{run_id}` | `POST` | **Yes** (`get_current_user`) | Verifies ownership. Grounded business Q&A using run facts, Cloudinary model/dataset tools. Returns 404 if not owned. |
| `/predict` *(legacy)* | `POST` | **Remove or scope** | Legacy un-scoped prediction endpoint. Remove if unused by UI; if kept for test compatibility, enforce `get_current_user` and ownership. |
| `/generate_report` *(legacy)* | `POST` | **Remove** | Replaced by `GET /runs/{run_id}/report` which streams PDF on demand from saved run. |

## 3. Environment Variables Audit

| Variable Name | Required / Optional | Service Scope | Description & Source |
| :--- | :--- | :--- | :--- |
| `SUPABASE_DB_URL` | **Required** | Backend | PostgreSQL connection string with session pooler from Supabase (*Project Settings > Database > Connection string*). |
| `SUPABASE_URL` | **Required** | Both | Supabase Project API URL (*Project Settings > API*). Used for Supabase Auth token validation on backend and login/signup on frontend. |
| `SUPABASE_ANON_KEY` | **Required** | Both | Supabase Anonymous public client key (*Project Settings > API*). Used for Auth verification header. Safe for frontend client. |
| `CLOUDINARY_CLOUD_NAME` | **Required** | Backend | Cloudinary cloud identifier (*Cloudinary Dashboard*). Backend only. |
| `CLOUDINARY_API_KEY` | **Required** | Backend | Cloudinary API Key (*Cloudinary Dashboard*). Backend only. |
| `CLOUDINARY_API_SECRET` | **Required** | Backend | Cloudinary API Secret (*Cloudinary Dashboard*). Sensitive credential, backend only. |
| `GROQ_API_KEY` | Optional | Backend | Groq Cloud API Key (*console.groq.com*). If blank, system falls back to rule-based insights. |
| `GROQ_MODEL` | Optional | Backend | Model identifier on Groq (default: `openai/gpt-oss-120b`). |
| `MAX_UPLOAD_SIZE_MB` | Optional | Backend | Maximum allowed uploaded file size in MB (default: `20`). |
| `CORS_ORIGINS` | Optional | Backend | Comma-separated allowed UI origins for CORS (default: `http://localhost:8501`). |
| `API_URL` | **Required** | Frontend | Base URL of deployed FastAPI backend (default: `http://localhost:8000`). |
| `TESTING` / `PYTEST_CURRENT_TEST` | Optional (Auto) | Backend / Tests | Bypasses remote calls and uses in-memory SQLite during automated test execution. |
